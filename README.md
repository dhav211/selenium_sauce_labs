## What is this?
This is my deep dive into Selenium and JUnit with a full test automation suite of saucedemo.com, which is a bare-bones ecommerce style website tailored for learning this kind of work. Although not a massively interesting endeavor I do believe it has some serious educational value.

## What I am testing?
I am strictly testing the frontend with this suite, as saucedemo doesn't have any sort of registration, advanced login other than matching username/password pairs, and any real database connectivity. However, it does supply me with ample opportunities to test various web elements such as input fields, drop down boxes, buttons, and all those fun interactive elements that can cause so many issues.

Trying my best to put on my QA hat and not only just have Selenium click the elements, I do hope to find ways to make those very elements misbehave and find some issues.
